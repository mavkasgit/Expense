Тест функционала исключений для массового импорта

Что было реализовано:

  • ✅ Компонент ExclusionSettings для управления исключающими словами
  • ✅ Интеграция в ColumnMappingModal как новая секция
  • ✅ Сохранение исключений в localStorage
  • ✅ Фильтрация строк по исключающим словам
  • ✅ Предпросмотр исключенных/включенных строк
  • ✅ Обновление статистики импорта

Как использовать:

  1. Откройте страницу массового импорта
  2. Загрузите файл или вставьте данные
  3. Откройте настройки столбцов
  4. Найдите секцию "🚫 Исключающие слова"
  5. Добавьте слова для исключения (например: "комиссия", "возврат", "отмена")
  6. Посмотрите предпросмотр - строки с этими словами будут помечены как исключенные
  7. Примените настройки - исключенные строки не будут импортированы

Функции компонента ExclusionSettings:

  • Добавление исключений: Поле ввода + кнопка "Добавить"
  • Удаление исключений: Кнопка ✕ на каждом исключении
  • Кликабельные исключения: Клик по исключению показывает все строки, которые оно исключает
  • Предпросмотр: Переключение между "Все", "Включенные", "Исключенные"
  • Полный предпросмотр: Кнопка "Показать все записи" для просмотра всех строк
  • Статистика: Счетчики включенных/исключенных строк для каждого исключения
  • Сохранение: Автоматическое сохранение в localStorage

🆕 Новые возможности:

  • ✅ Перемещена над тестовой строкой - секция исключений теперь находится перед детальным разбором
  • ✅ Кликабельные исключения - клик по исключению "(слово) (количество)" открывает модальное окно со всеми исключенными строками
  • ✅ Полный предпросмотр - кнопка "📊 Показать все записи" открывает все строки в модальном окне
  • ✅ Счетчики для каждого исключения - показывает сколько строк исключает каждое слово
  • ✅ Секция "Скрытые столбцы" по умолчанию свернута - стрелка перемещена влево, состояние сохраняется в localStorage
  • ✅ Секция "Тестовая строка" по умолчанию свернута - состояние сохраняется в localStorage, стрелка уже была слева
  • ✅ Убран лишний элемент - удален лишний div который создавал пустое пространство снизу секции
  • ✅ Добавлены тултипы на все секции - вопросики с подробными описаниями функционала

Примеры исключающих слов для банковских выписок:

  • "комиссия" - исключит все операции с комиссиями
  • "возврат" - исключит возвраты средств
  • "отмена" - исключит отмененные операции
  • "пополнение" - исключит пополнения счета
  • "перевод на счет" - исключит исходящие переводы
