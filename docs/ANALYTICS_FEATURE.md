# 📊 Analytics Dashboard - Новая Фича

## Обзор

Реализован полноценный Analytics Dashboard для детальной визуализации и анализа расходов пользователя.

## Что было сделано

### 1. Server Actions для аналитики (`src/lib/actions/analytics.ts`)

Созданы новые server actions для получения данных аналитики:

- **`getTimeSeriesData`** - получение данных временного ряда (по дням/неделям/месяцам)
- **`getCategoryAnalytics`** - анализ расходов по категориям с процентами
- **`getCityAnalytics`** - анализ расходов по городам
- **`getPeriodComparison`** - сравнение текущего и прошлого периода
- **`getExpenseHeatmap`** - данные для тепловой карты расходов

### 2. Компоненты визуализации (`src/components/analytics/`)

#### Графики (используется recharts):
- **`TimeSeriesChart.tsx`** - линейный график динамики расходов
- **`CategoryPieChart.tsx`** - круговая диаграмма по категориям
- **`CategoryBarChart.tsx`** - столбчатая диаграмма

#### UI компоненты:
- **`StatCard.tsx`** - карточки статистики с трендами
- **`TopList.tsx`** - топ категорий/городов с прогресс-барами
- **`PeriodComparisonCard.tsx`** - сравнение периодов
- **`ExpenseHeatmap.tsx`** - календарная тепловая карта (GitHub-style)

#### Основной компонент:
- **`AnalyticsContent.tsx`** - главный компонент с фильтрами и всеми видами

### 3. Обновленная страница Analytics

`src/app/(dashboard)/analytics/page.tsx` - теперь полноценная страница с:
- Фильтрами по периодам (Неделя, Месяц, 3 месяца, Год, Все время)
- Режимами просмотра (Обзор, Категории, Города, Тренды)
- Адаптивным дизайном

## Возможности Dashboard

### Режим "Обзор"
- 📊 Карточки со статистикой:
  - Всего потрачено (с трендом)
  - Всего расходов (с трендом)
  - Категоризировано
  - Без категории
- 📈 Сравнение с прошлым периодом
- 🏆 Топ-5 категорий
- 🌍 Топ-5 городов

### Режим "Категории"
- 🥧 Круговая диаграмма распределения
- 📊 Столбчатая диаграмма по сумме
- 📋 Полный список всех категорий с процентами

### Режим "Города"
- 📊 Столбчатая диаграмма расходов по городам
- 📍 Полный список городов с суммами и количеством

### Режим "Тренды"
- 📈 Линейный график динамики расходов
- 🗓️ Тепловая карта календаря (при фильтре "Год")

## API Server Actions

### Получение временного ряда

```typescript
const result = await getTimeSeriesData({
  dateFrom: '2024-01-01',
  dateTo: '2024-12-31',
  groupBy: 'week' // 'day' | 'week' | 'month'
})
```

### Получение аналитики по категориям

```typescript
const result = await getCategoryAnalytics({
  dateFrom: '2024-01-01',
  dateTo: '2024-12-31',
  limit: 10
})
```

### Сравнение периодов

```typescript
const result = await getPeriodComparison(
  '2024-11-01', // currentFrom
  '2024-11-30', // currentTo
  '2024-10-01', // previousFrom
  '2024-10-31'  // previousTo
)
```
