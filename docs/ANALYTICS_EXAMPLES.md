# 📊 Analytics Dashboard - Примеры использования

## Обзор функционала

Analytics Dashboard предоставляет мощные инструменты для визуализации и анализа ваших расходов.

## Доступ к аналитике

Перейдите на страницу `/analytics` в защищенной зоне dashboard.

## Фильтры периодов

### Доступные периоды:
- **Неделя** (7d) - последние 7 дней
- **Месяц** (30d) - последние 30 дней
- **3 месяца** (90d) - последние 90 дней
- **Год** (1y) - последние 365 дней
- **Все время** (all) - все ваши расходы

### Пример использования:
```
1. Откройте страницу Аналитика
2. Выберите нужный период в верхней части экрана
3. Данные автоматически обновятся
```

## Режимы просмотра

### 1. Обзор (Overview)

**Что показывает:**
- 4 карточки со статистикой:
  - 💰 Всего потрачено (с трендом)
  - 📊 Всего расходов (с трендом)
  - ✅ Категоризировано
  - ❓ Без категории
- Сравнение с предыдущим периодом
- Топ-5 категорий
- Топ-5 городов

**Когда использовать:**
- Быстрая оценка финансового состояния
- Сравнение текущих трат с прошлым периодом
- Выявление основных направлений расходов

**Пример инсайтов:**
```
"Вы потратили 45,000₽ в этом месяце,
это на 15% больше, чем в прошлом месяце"

"Топ категория: Еда - 18,500₽ (41.1%)"
"Топ город: Москва - 32,000₽ (71.1%)"
```

### 2. Категории (Categories)

**Что показывает:**
- Круговая диаграмма распределения по категориям
- Столбчатая диаграмма сумм по категориям
- Полный список всех категорий с:
  - Суммой расходов
  - Количеством транзакций
  - Процентом от общих трат
  - Прогресс-баром

**Когда использовать:**
- Детальный анализ трат по категориям
- Выявление категорий с наибольшими расходами
- Планирование бюджета по категориям

**Пример использования:**
```
1. Перейдите в режим "Категории"
2. Изучите круговую диаграмму для общего понимания
3. Посмотрите столбчатую диаграмму для сравнения категорий
4. Прокрутите вниз к полному списку для деталей
```

### 3. Города (Cities)

**Что показывает:**
- Столбчатая диаграмма расходов по городам
- Полный список городов с:
  - Суммой трат в каждом городе
  - Количеством расходов
  - Процентом от общих трат

**Когда использовать:**
- Анализ трат во время путешествий
- Сравнение расходов в разных городах
- Планирование поездок на основе исторических данных

**Пример инсайтов:**
```
"В Санкт-Петербурге вы тратите в среднем
на 30% больше, чем в Москве"

"Топ-3 города по тратам:
1. Москва - 85,000₽
2. Санкт-Петербург - 42,000₽
3. Сочи - 28,000₽"
```

### 4. Тренды (Trends)

**Что показывает:**
- Линейный график динамики расходов во времени
- Календарная тепловая карта (при фильтре "Год")

**Когда использовать:**
- Отслеживание изменений трат во времени
- Выявление паттернов и сезонности
- Прогнозирование будущих расходов

**Пример анализа:**
```
График показывает:
- Пики трат в выходные дни
- Увеличение расходов в конце месяца
- Снижение трат в период отпуска

Тепловая карта показывает:
- Самые "дорогие" дни года
- Периоды минимальных трат
- Паттерны повторяющихся расходов
```

## Интерпретация трендов

### Положительные тренды (↑ красный)
```
Текущий период: 50,000₽
Прошлый период: 40,000₽
Изменение: ↑ +25.0%
```
**Значит:** Вы тратите больше, чем в прошлом периоде

### Отрицательные тренды (↓ зеленый)
```
Текущий период: 35,000₽
Прошлый период: 45,000₽
Изменение: ↓ -22.2%
```
**Значит:** Вы тратите меньше, чем в прошлом периоде (экономия!)

## Практические сценарии

### Сценарий 1: Еженедельная проверка бюджета
```
1. Выберите период "Неделя"
2. Перейдите в режим "Обзор"
3. Проверьте общую сумму трат
4. Сравните с прошлой неделей
5. Изучите топ категорий
```

### Сценарий 2: Планирование месячного бюджета
```
1. Выберите период "Месяц"
2. Перейдите в режим "Категории"
3. Изучите распределение по категориям
4. Определите категории для оптимизации
5. Установите цели на следующий месяц
```

### Сценарий 3: Анализ годовых трат
```
1. Выберите период "Год"
2. Перейдите в режим "Тренды"
3. Изучите линейный график динамики
4. Посмотрите на календарную тепловую карту
5. Найдите паттерны и сезонность
6. Спланируйте бюджет на следующий год
```

### Сценарий 4: Планирование поездки
```
1. Выберите период "Все время"
2. Перейдите в режим "Города"
3. Найдите город, куда планируете поехать
4. Посмотрите средние траты в этом городе
5. Запланируйте бюджет поездки
```

## Советы по использованию

### 💡 Совет 1: Регулярный мониторинг
Проверяйте аналитику хотя бы раз в неделю, чтобы:
- Не выбиваться из бюджета
- Вовремя замечать избыточные траты
- Корректировать расходы

### 💡 Совет 2: Используйте сравнение периодов
Сравнение с прошлым периодом помогает:
- Отслеживать прогресс
- Видеть динамику трат
- Мотивировать к экономии

### 💡 Совет 3: Анализируйте тренды
Линейный график показывает:
- Когда вы тратите больше всего
- Есть ли сезонность в тратах
- Как меняются привычки

### 💡 Совет 4: Используйте календарную карту
Тепловая карта помогает:
- Найти паттерны трат
- Увидеть "дорогие" дни
- Спланировать крупные покупки

### 💡 Совет 5: Детализируйте категории
Список категорий показывает:
- Куда уходят основные деньги
- Какие категории можно оптимизировать
- Где есть резервы для экономии

## FAQ

**Q: Почему не отображаются данные?**
A: Убедитесь, что у вас есть расходы за выбранный период.

**Q: Как изменить период?**
A: Нажмите на кнопки периода в верхней части страницы.

**Q: Что означают проценты в трендах?**
A: Это изменение относительно предыдущего периода той же длительности.

**Q: Можно ли экспортировать данные?**
A: Функция экспорта планируется в будущих версиях.

**Q: Как читать тепловую карту?**
A: Чем темнее цвет, тем больше вы потратили в этот день.
