# Задачи: Функционал исключений и дубликатов для массового импорта

## 1. Система исключающих слов

- [ ] 1.1 Создать компонент управления исключающими словами
  - Интерфейс для добавления/удаления исключающих слов
  - Сохранение в localStorage или базе данных
  - Предварительный просмотр какие строки будут исключены

- [ ] 1.2 Реализовать логику фильтрации по исключающим словам
  - Проверка каждой строки импорта на наличие исключающих слов
  - Поддержка регистронезависимого поиска
  - Возможность исключения по любому полю (описание, заметки, etc.)

- [ ] 1.3 Добавить UI индикаторы исключенных строк
  - Показать количество исключенных строк
  - Возможность просмотра исключенных строк
  - Кнопка для временного отключения фильтрации

## 2. Обнаружение дубликатов

- [ ] 2.1 Создать систему обнаружения дубликатов внутри файла
  - Сравнение по настраиваемым критериям (сумма + дата + описание)
  - Возможность выбора полей для сравнения
  - Группировка найденных дубликатов

- [ ] 2.2 Реализовать проверку дубликатов с существующими расходами
  - API endpoint для поиска похожих расходов в базе
  - Сравнение с расходами пользователя за определенный период
  - Настраиваемые критерии совпадения

- [ ] 2.3 Добавить UI для управления дубликатами
  - Список найденных дубликатов с возможностью выбора
  - Кнопки "Оставить все", "Оставить первый", "Выбрать вручную"
  - Предварительный просмотр какие записи будут сохранены
